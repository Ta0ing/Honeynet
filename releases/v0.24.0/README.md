# Honeynet Server v0.24.0

预构建的完整 Linux AMD64 发行包：

- 文件：`honeynet-server-0.24.0-linux-amd64.tar.gz`
- 平台：Linux AMD64
- 内容：Server、Agent、Web 控制台、规则、安装脚本与蜜罐资源
- 存储：Git LFS

下载后执行以下命令并与同目录的 `.sha256` 文件比对：

```bash
sha256sum honeynet-server-0.24.0-linux-amd64.tar.gz
```
